# 실제 카카오톡 내보내기 형식 수집 절차 (Phase 1.8, DD-021)

실제 대화 파일은 **AI 개발 도우미를 포함해 누구에게도 공유하지 않습니다.** 공유하는 것은 아래 도구가 만든 **내용 없는 구조 보고서**뿐입니다.

## 1. 샘플 준비 (사용자 PC에서만)
1. 저장소 **밖**에 폴더를 만듭니다. 예: `C:\TalkProPrivate\exports`
   - `D:\Talk_pro` 안에 두지 마세요. `.gitignore`가 막아 주지만, 실수로 커밋되는 경로를 원천 차단하기 위해서입니다.
   - 가능하면 BitLocker 드라이브나 Windows "콘텐츠를 암호화하여 데이터 보호(EFS)"를 켠 폴더를 쓰세요.
2. 다음 조합으로 **본인이 참여한 대화**를 내보내 이 폴더에 둡니다. 가능한 것만 준비하면 됩니다.

| # | 기기 | 내보내기 방법 | 비고 |
|---|---|---|---|
| A | Windows PC 카카오톡 | 채팅방 메뉴 → 대화 내용 → 대화 내보내기 | 1:1 한 개, 단톡 한 개 |
| B | Android | 채팅방 설정 → 대화 내용 내보내기 → 텍스트만 보내기 | |
| C | iPhone | 채팅방 설정 → 대화 내용 내보내기 → 텍스트 메시지만 보내기 | |
| D | Mac 카카오톡 | 채팅방 설정 → 대화 내용 관리 → 대화 내용 저장 | 있으면 |
| E | 영어 UI | 휴대폰 언어를 영어로 바꾼 상태에서 B 또는 C | 있으면 |

   사진, 시스템 메시지(입장·퇴장), 여러 줄 메시지, 날짜가 바뀌는 구간이 포함된 대화가 좋습니다.

## 2. 구조 보고서 만들기
Visual Studio 개발자 PowerShell 또는 터미널에서 실행합니다(경로는 예시).
```bash
dotnet run --project D:\Talk_pro\tools\FormatProbe -- profile C:\TalkProPrivate\exports\pc.txt C:\TalkProPrivate\exports\android.txt C:\TalkProPrivate\exports\iphone.txt
```
- 도구는 파일을 **읽기만** 하고, 화면에만 출력합니다. 파일을 쓰지 않고, 네트워크도 쓰지 않습니다.
- 파일 이름과 경로는 출력하지 않으며 `file #1`, `file #2` 순서로만 표시합니다. 위 명령의 **파일 순서(PC/Android/iPhone…)를 따로 적어 두세요.**

## 3. 보고서 확인 후 공유
- 보고서에서 이름·본문은 `⟦H3⟧`(한글 3자), `⟦A5⟧`(영문 5자), `⟦D4⟧`(숫자 4자리)처럼 길이 토큰으로 바뀝니다. 남는 것은 형식 단어(오전/오후, 요일, "님이 들어왔습니다" 등)와 문장부호뿐입니다.
- **공유 전에 직접 훑어보고**, 혹시 실제 이름이나 문장이 보이면 그 줄을 지우고 알려 주세요. 그 경우 도구 결함이므로 고치겠습니다.
- 보고서 텍스트와 "file #1 = PC, #2 = Android…" 대응표만 전달해 주세요.

## 현재 상태 (2026-10-13)
- **카카오톡 PC(Windows/Mac) 내보내기**: 지원(`kakao.pc.ko.v1`). 실제 1:1 대화 1개로 `validate` 100% 확인, 모든 빌드에 등록(DD-027).
- **Android·iPhone 내보내기, 단톡방의 입장·퇴장 줄**: 아직 미지원. 위 절차로 각 형식의 보고서를 주시면 추가합니다.

## 4. 이후 단계
1. 보고서를 근거로 실제 형식 어댑터(`WindowsKoAdapter`, `AndroidKoAdapter`, `IosKoAdapter`)를 작성합니다.
2. 같은 형식의 **합성** Golden 샘플을 생성기에 추가하고 테스트를 만듭니다.
3. 사용자가 PC에서 `validate` 명령으로 실제 파일의 파싱 성공률을 확인합니다(이 보고서도 내용이 없습니다).
   ```bash
   dotnet run --project D:\Talk_pro\tools\FormatProbe -- validate C:\TalkProPrivate\exports\pc.txt
   ```
4. 줄 단위 파싱 성공률 99% 이상이면 Release 빌드에 실제 어댑터를 등록합니다.
