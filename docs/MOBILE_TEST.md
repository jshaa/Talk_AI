# 휴대폰 테스트 안내 (Android 앱 · iPhone 웹 뷰어) — DD-026

> **카카오톡 PC(Windows/Mac)에서 '대화 내보내기'로 저장한 .txt**를 읽습니다(DD-027). 휴대폰에서 내보낸 형식은 아직 지원하지 않습니다.
> 앱 안의 **"합성 예시 대화"**(Debug)로도 시험할 수 있습니다. 실제 대화 파일은 다른 사람에게 보내거나 공유하지 마세요.

## 1. Android 앱 (APK, 기기 안 AI 포함)

**설치 파일**: `artifacts/TalkPro-PoC-debug.apk` (약 70MB, 테스트용 디버그 서명)

1. APK를 휴대폰으로 옮깁니다(USB 파일 복사 등). 메신저나 클라우드로 보내지 않는 편이 안전합니다.
2. 휴대폰에서 파일을 열고 "출처를 알 수 없는 앱 설치"를 이 한 번만 허용합니다.
3. 요구 사항: **Android 12 이상**, arm64(대부분의 최근 휴대폰). AI 기능은 **RAM 8GB 이상** 권장.
4. 처음 실행 → 왼쪽 메뉴:
   - **가져오기**: 서약 체크 → "파일 선택" → "합성 예시 대화 (테스트용)" → 본인 `UserA` 지정 → 개인정보 검토 → 암호화 저장
   - **데이터셋**: 저장된 데이터셋 선택 → "선택한 데이터셋 분석"
   - **기억 검색**: 단어 검색(이 기기에서는 뜻 검색 미지원)
   - **로컬 AI**: "모델 내려받기"(Phi-4-mini, 약 4.9GB, **Wi-Fi 권장**). 파일마다 SHA-256으로 검증합니다. 끊겨도 다시 누르면 이어서 받습니다.
   - **답장 초안**: 모델 설치 후 데이터셋·받은 메시지를 넣고 "초안 만들기" → 수락·보류·되묻기 초안. 복사만 되고 60초 뒤 클립보드에서 지워집니다.
5. 확인할 점(PoC 체크): 첫 초안까지 걸린 시간, 휴대폰 발열, 메모리 부족으로 앱이 꺼지는지.

**개인정보**: 대화·키·모델은 앱 전용 저장소에만 있고, 클라우드 백업·기기 간 이전에서 제외됩니다. 인터넷은 모델을 내려받을 때(huggingface.co)만 쓰며 그 요청에는 대화 내용이 들어가지 않습니다.

**알려진 제한**: 16KB 메모리 페이지 기기(일부 Android 15/16 설정)에서는 기기 안 AI가 로드되지 않을 수 있습니다(라이브러리 `libmat.so` 문제, DD-026).

## 2. iPhone 웹 뷰어 (브라우저 안에서만 실행, AI 없음)

PC에서 한 번 준비합니다.

```bash
dotnet publish src/TalkPro.Web -c Release -o artifacts/web
```

```bash
dotnet run --project tools/WebViewerHost -- "D:\Talk_pro\artifacts\web\wwwroot" 5080
```

1. 콘솔에 표시된 주소(예: `http://192.168.x.x:5080/`)를 **같은 Wi-Fi**의 iPhone Safari에서 엽니다. Windows 방화벽이 물으면 "개인 네트워크"만 허용하세요.
2. "합성 예시 대화 불러오기" → 본인 `UserA` 선택 → 서약 체크 → "분석하기" → 분석 결과와 단어 검색.
3. 대화 파일은 **iPhone 브라우저 안에서만** 읽고 분석합니다. 서버로 올라가지 않고 저장되지 않으며, 새로고침하면 사라집니다. 호스트는 앱 파일만 보내고, 페이지가 다른 곳으로 데이터를 보내지 못하도록 CSP를 겁니다.
4. 테스트가 끝나면 콘솔에서 Ctrl+C로 호스트를 끕니다.

## 3. 개발자 확인 명령

- 기기 안 AI(같은 엔진·모델)를 PC에서 확인: `dotnet run -c Release --project tools/OnDeviceSmoke`
- APK 다시 만들기: `dotnet build src/TalkPro.Mobile -c Debug` → `src/TalkPro.Mobile/bin/Debug/net10.0-android/com.talkpro.poc-Signed.apk`
